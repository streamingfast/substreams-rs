# Substreams

Substreams is a powerful blockchain indexing technology, developed for The Graph Network.

It enables you to write Rust modules, composing data streams alongside the community, and provides extremely high performance indexing by virtue of parallelization, in a streaming-first fashion.

It has all the benefits of the Firehose, like low-cost caching and archiving of blockchain data, high throughput processing, and cursor-based reorgs handling.

### Library Documentation

#### Quick Protobuf

This crate supports [quick-protobuf](https://github.com/tafia/quick-protobuf) as an alternative to the default Prost protobuf library. Quick-protobuf offers faster compilation times and smaller binary sizes, making it ideal for WASM targets.

##### Enabling Quick Protobuf

1. **Add the feature to your Cargo.toml dependencies:**

```toml
[dependencies]
substreams = { version = "0.7", features = ["quick-protobuf"] }
quick-protobuf = "0.8"
```

2. **Use the `quick_protobuf` macro option in your handlers:**

```rust
use substreams::handlers::map;
use quick_protobuf::{MessageRead, MessageWrite};

// Your protobuf types generated by quick-protobuf
mod pb {
    include!(concat!(env!("OUT_DIR"), "/mod.rs"));
}

use pb::{Block, MyOutput};

#[substreams::handlers::map(quick_protobuf)]
fn map_blocks(block: Block) -> MyOutput {
    MyOutput {
        number: block.number,
        hash: block.hash,
    }
}
```

##### Generating Quick Protobuf Code

Use quick-protobuf's code generator in your `build.rs`:

```rust
use quick_protobuf_codegen::{Codegen, CustomizeCallback};

fn main() {
    Codegen::new()
        .out_dir("src/pb")
        .input("proto/myschema.proto")
        .include("proto")
        .customize(CustomizeCallback::default())
        .run()
        .expect("Codegen failed");
}
```
